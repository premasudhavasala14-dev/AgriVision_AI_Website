# AgriVision AI — College Project Website

A presentation-ready Flask website prototype for an AI-powered smart agriculture project.

## Run it

1. Open this folder in VS Code.
2. Open the VS Code terminal.
3. Run:
   `pip install -r requirements.txt`
4. Then run:
   `python app.py`
5. Open:
   `http://127.0.0.1:5000`

## Important

The crop diagnosis and crop recommendation are prototype/demo interactions. They do not use a real trained AI model yet. This is intentional so the website can be demonstrated without setting up a machine-learning backend.

For a final project, the JavaScript demo logic can later be connected to a real Python ML model/API.
